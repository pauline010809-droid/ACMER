# ACMER 产品图片库

ACMER 激光雕刻机各 SKU 的上架图片，按「型号+功率 → SKU」两级目录归档。

## 目录结构

```
<型号 功率>/                     例如 S1 2.5W、P1 S PRO 48W
  <SKU>_<颜色>/                例如 0082010051_Black
    <型号 功率>_<SKU>_<颜色>_01.jpg   01 为主图，后续按消费者关注度排序
```

- 共 **33 个 SKU**、**18 个型号功率分组**、**389 张** 1:1 方图（.jpg，≥1000px）。
- 图片顺序：01 白底整机主图 → 功率/切割能力 → 精度 → 速度 → 幅面 → 材料成品 → 软件与易用 → 安全 → 结构做工 → 配件生态 → 参数表 → 包装清单 → 场景。
- 文件名与本地归档目录 `产品图片_系列功率颜色_已排序/<型号 功率>_<SKU>_<颜色>/` 完全一致，便于反查。
- `SKU_目录索引.csv` 列出每个 SKU 的型号功率、颜色、本地文件夹名、仓库路径、图片数、主图文件名，以及 K1 专属的滤光盖色与套图来源。

## K1 的盖色通用规则

K1 只有两套供应商套图，**按滤光盖色区分、不分功率**：

| 滤光盖色 | 供应商套图 | 适用 SKU |
| --- | --- | --- |
| 茶色 / 黑琥珀 | `K1/黑茶` | 0082050031 (3.5W)、0082050037 (7W)、0082050043 (12W) |
| 墨绿色 | `K1/黑绿` | 0082050055 (2.5W)、0082050061 (3.5W)、0082050067 (7W)、0082050073 (12W) |

7 个 K1 SKU 均使用所属盖色的**完整 14 张**、顺序一致。其中 `13` 为参数规格表，内容（150×150mm 幅面 / 0.08×0.08mm 光斑 / 10000mm/min / 0.01mm 精度 / 软件兼容）为全功率通用规格、不含任何功率数字，可安全用于所有功率。
